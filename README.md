# Карта кампуса БГУ

Интерактивная SVG-карта кампуса с поиском аудиторий и маршрутом «от пары к паре».

**Первая локация:** учебный корпус БГУ по адресу **г. Минск, ул. Карла Маркса, 31** (экономический и филологический факультеты, 5 этажей, метро «Купаловская»).

Состав: 1 этаж — входная зона (вахта, турникеты ×2, гардероб, WC Ж/М), фудкорт, актовый зал, дворик, «наша кафедра», вход в нижние раздевалки, 101–104, 112, 113; 2П — ФИЛФАК + WC; 2 — главный деканат (64) и деканат; 3П — ФИЛФАК; 3 — 304, 307, 316 + WC Ж/М; 4П — библиотека (71), 71А, 63, 63А + WC Ж/М; 4 — спортзал, раздевалки Ж/М, 404, 407, WC; 5П — 86 + WC М/Ж. Уровни 2–5П — условная локальная раскладка, 1 этаж — два блока (актовый зал/аудитории сверху, вход снизу). У комнат поле `conf`:

  - `hypothesis` — номер из расписаний ЭФ, размещён рядом с родственными (пунктир на карте).

- [`room-usage.csv`](data/room-usage.csv) — частота аудиторий в расписании ЭФ (для приоритизации).
- [`data/room-usage.csv`](data/room-usage.csv) — сколько раз каждая аудитория встречается в расписании ЭФ (осень 2026/27) и откуда взят номер: пригодится для приоритизации комнат и пресетов «от пары к паре».
- [`assets/floor-1.svg` … `floor-4.5.svg`](plan-preview.html) — статичные планы 8 уровней, генерируются командой `node tools/generate-floor-plans.mjs` из v4-данных.
- [`plan-preview.html`](plan-preview.html) — статичное превью с переключателем 8 уровней (открывается в браузере без сборки).
- [`index.html`](index.html) — **интерактивная карта с поиском** (mobile-first, геометрия со стенда): вводите «63а», «316», «деканат», «фудкорт», «туалет», «спортзал» → карта переключается на нужный из 10 уровней, подсвечивает комнату и показывает карточку («как найти»: уровень, часть схемы, ближайшая лестница). Пан/зум (щипок, колесо, drag), тап по комнате, ссылки вида `#room=63А`. Данные — снапшот `economics-building.json`, встроенный в страницу, чтобы она открывалась двойным кликом без сервера: при обновлении JSON синхронизируйте блок `<script id="building-data">`.

Официального поэтажного плана корпуса в открытом доступе нет — геометрия в SVG условная (коридор + ряды комнат). Когда появится точный план (фото стенда, обмеры), достаточно заменить полигоны комнат в JSON — логика не изменится.

## Скоуп проекта

Выбранные направления:

### 1. Карта и поиск
Интерактивный SVG, поиск по аудиториям, корпусам, кафедрам, туалетам, столовым, входам.

### 2. Маршрутизация «от пары к паре»
Пользователь вводит две аудитории — карта строит маршрут: этаж → лестница/лифт → другой корпус. Расчёт «сколько минут идти» с учётом того, что между парами 10–15 минут.

### 5. Социальный слой (отложено на v2)
Пользовательские метки на карте: «здесь розетки», «тихое место для подготовки», «где сейчас меньше всего людей в столовой».

## Дорожная карта

### v1 — ядро (карта + поиск + маршрут)

> **✅ v1 выпущена 2026-10-25** и принята пользователем: [annamalinets-byte.github.io/campus-bsu](https://annamalinets-byte.github.io/campus-bsu/). Отличие от плана ниже: вместо графа коридоров сделан упрощённый пошаговый маршрут от входа (полный граф и «от пары к паре» перенесены в v2); скоуп сужен до главного корпуса, этажи 1–5.

- SVG-карта одного корпуса: этажи 1–5 корпуса «К. Маркса, 31», аудитории как полигоны с `id` и подписями.
- Масштабирование/панорамирование (колесо + drag), переключатель этажей.
- Поиск с автодополнением: ввод «63А» или «кафедра цифровой экономики» → подсветка комнаты на карте + карточка (этаж, крыло, подсказка «как найти»). Нормализация ввода: «63а», «63-А», «63А».
- Маршрут по этажу: граф коридоров (узлы = перекрёстки, двери, лестницы), поиск пути BFS/Dijkstra поверх SVG.
- Межэтажный маршрут: маршрут до лестницы, смена этажа, продолжение пути.
- Режим «от пары к паре»: два поля «Откуда / Куда» + пресеты (например, «63 → 316»), оценка времени ходьбы (≈1,5–2 мин на этаж).

**Вне скоупа v1:** второй корпус и переходы между зданиями, импорт реального расписания, геолокация, авторизация, мобильное приложение.

### v2 — социальный слой

- Пользовательские метки на карте: розетки, тихие места, загруженность столовой.
- Категории меток и фильтры поверх карты.

## Техническая основа

- **React + Vite** (или ванильный JS): компоненты этажей, состояние поиска и маршрута.
- **Данные отдельно от кода**: JSON с описанием здания — комнаты (`{id, name, floor, polygon, type}`), узлы графа коридоров и рёбра. Добавление корпуса = новый JSON, а не новая логика.
- **Оцифровка этажей**: наложить фото/план этажа под SVG, обводить комнаты поверх. Главная трудоёмкость проекта — начать с одного этажа и довести его до конца.
- **Анимация маршрута**: отрисовка пути с `stroke-dashoffset` — дешёвый и эффектный штрих.

## Идеи на вырост (не в текущем скоупе)

- Импорт расписания из личного кабинета → уведомление «пора выходить».
- Поиск по типу: «ближайший туалет», «где печатать».
- Оверлей «доступная среда»: маршруты через лифты для маломобильных.
- Галерея «как выглядит вход» — фотоориентиры.
